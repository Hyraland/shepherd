# 伊犁 · 牧羊

基于 three.js 的第一人称草原牧羊：一条走不到尽头的东西向河谷，谷底是草甸和蜿蜒的溪流，
两侧是云杉林坡，东边地平线上是雪山；朝着太阳望去，远处的溪流反着金光。
真实感光照（太阳投影阴影、蓝色天光、飘过的云影），细密的草地被一阵阵风吹过，羊群聚在视线前方。
画面里没有任何文字和 UI。

## 运行

浏览器不允许直接用 `file://` 打开 ES 模块，需要起一个静态服务器。用项目自带的 `serve.py`，
它给每个文件都加了 `Cache-Control: no-store`，改完代码刷新就是最新版本
（`python3 -m http.server` 不发缓存头，浏览器会按启发式规则缓存 JS 模块，常常看到旧版本）：

```bash
python3 serve.py
```

然后打开 http://localhost:8000 。three.js 从 CDN 加载，需要联网。

## 操作

| 操作 | 效果 |
| --- | --- |
| 单击 | 唤来一只小羊（从视野外跑进来，最多 50 只） |
| 双击 | 送走一只小羊（双击某只就送走它，否则送走离点击处最近的那只） |
| 拖动 / 方向键 | 环顾四周；默认往视线方向走，羊群聚在视线前方跟着你 |
| 空格 | 停下 / 继续走 |
| R | 切换走法：自由漫步（往视线方向走） / 沿固定的环形小路走（以当前位置为中心） |

## 无尽的河谷

- 沿着河谷（东西方向）可以一直走下去：地形和树按 256m 的区块在人周围随走随生成，走远了就回收，没有接缝、也不会重复。
- 横跨河谷方向，靠近两边林坡时脚步会慢慢顺着林边转开（不会撞上看不见的墙）。
- 地平线上的雪山是一圈跟着人走的远景，像天空盒一样没有视差，所以永远走不到。

## 开发：画面调节面板

右上角的面板（按 **G** 显示 / 隐藏），最上面是帧率，下面分四组：

- **草地**：二分色开关、亮面颜色、亮面深色（叶根和深一些的草丛）、暗面颜色、明暗分界、分界柔和度、深色的多少、野花（0 = 没有花）
- **羊**：插画光影开关（关掉是写实材质）、亮面 / 暗面颜色、暗面靠向草地暗面的程度、明暗分界、柔和度、
  贴图细节（0 = 平涂）、毛绒凹凸（只在近处）、边缘亮光、整体亮度、向阳面提亮
- **溪流**：水色（深色的水底）、天空倒影、波纹细碎程度、阳光闪光强度、远处闪光颜色（朝着太阳望去远处溪流的金光）
- **天空与太阳**：太阳高度、太阳方位（0 = 顺河谷向西，转动太阳不会转动河谷）、阳光 / 天光强度、
  天顶 / 地平线颜色、地平线浅色带高度、远处雾气、曝光（只影响写实的部分：水、林、山）、强光辉光（太阳和水面闪光周围的光晕）；云影的覆盖、浓淡（云影是介于亮面和暗面之间的一层，1 = 和投影一样暗）、边缘柔和、飘动速度

颜色选的就是屏幕上最终看到的颜色（已抵消曝光和色调映射）。每次改动都会存到浏览器，
并通过 `serve.py` 写回项目根目录的 **tuning.json**——启动时以它为默认值，我也能直接读到。

面板底部有**预设**：选一个再点“套用这个预设”。“原野”参考 earth_history 结尾的草地、天空和河流；
“我上一版调的”是之前手动调好的那组。预设不改羊的参数。

## 开发：对比小羊模型

- 主场景里按数字键 **1–3** 切换模型，**M** 轮换；也可以用 `?sheep=cgtrader|dibarts|cartoon`。
  选择会记在浏览器里，切换时左下角会短暂显示当前模型名。
- `compare.html`：几种模型并排站着、同样的光照，可切换吃草 / 抬头 / 走路 / 小跑。

| 键 | 模型 | 说明 |
| --- | --- | --- |
| 1 | Realistic Sheep · WildMesh3D（CGTrader） | 写实贴图；头部单独点头/转头。CGTrader 版税授权：公开发布前需加密打包，见 CREDITS.md |
| 2 | Sheep · DibArts | 低面数 |
| 3 | Cartoon sheep · _Yen_ | 卡通高模，头部单独点头/转头 |

这几个都是不带骨骼的静态模型：腿部在顶点着色器里按步伐摆动（对角线两条腿同相），身体走路时轻晃、吃草时前倾。

## 结构

- `src/main.js`：场景组装、光照与阴影、输入、渲染循环、模型切换
- `src/walker.js`：固定的环形步道与第一人称相机
- `src/flock.js`：羊群行为（聚到视线前方；吃草/赶路、从众跟随、分离/对齐/聚合）
- `src/sheep.js`：羊的骨架（由羊群逻辑摆姿势）、接触阴影
- `src/sheepModels.js`：外部 glTF 模型的加载、归一化、腿部摆动和头部转动
- `src/grass.js`：跟随相机的两层短草（一丛丛长，两层之间逐根交替没有分界；阵风、云影、日照阴影，溪流里不长草）
- `src/scenery.js`：雪岭云杉（按远观做的精细模型 + 600 米外的简化版）
- `src/terrain.js`：河谷地形与着色（林地、溪水的波纹倒影与闪光、自然的湿土岸、远处的野花、冲沟积雪）、区块网格、地平线远景圈
- `src/world.js`：无尽河谷的区块管理（随走随生成地形和树，远处网格更粗）
- `src/rivers.js`：溪流的解析定义（JS 与 GLSL 共用一套参数）
- `src/sky.js`：蓝天（天顶到地平线的浅色带）、太阳、头顶的云
- `src/flowers.js`：近处的野花（远处的花画在地面上）
- `src/noiseTexture.js`：着色器共用的预烘噪声纹理（附带与之一致的 CPU 采样，用来种树）
- `src/post.js`：强光辉光（bloom）、Khronos PBR Neutral 色调映射
- `src/config.js`：太阳方向、光照强度、配色、草地二分色默认值、羊的上限等参数
- `src/devPanel.js`、`src/tuning.js`：开发用的画面调节面板，参数存取（tuning.json）
- `src/sheepShader.js`：插画风的羊（与草地同一套受光量：太阳朝向 × 云影 × 投影）
